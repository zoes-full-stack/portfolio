FormStudio is a form builder built for teams who want forms that actually connect to their workflow, not just collect submissions.
{:.lead}

Many form tools stop at “submit.” FormStudio is designed to go further: clean creation, structured data, and integrations that turn entries into action, documents, and automation.

- Table of Contents
{:toc .large-only}

## My Role
- UX + UI design refinements (clarity, hierarchy, flow)
- Frontend implementation support (design → build alignment)
- Integration thinking for workflows (notifications, automation hooks)

## Technologies Used
`Vue 3` | `Google Cloud Functions` | `Serverless Microservices` | `Webhooks` | `Zapier` | `Email Notifications`

## Key Features
- Form builder with structured fields
- Clean, embeddable forms
- Submission management + workflow-friendly output
- Integration-ready architecture (webhooks + automation)

## Design Notes
- Designed for **clarity and speed**: faster building, fewer confusing steps
- Emphasis on **calm UI**: predictable patterns, gentle feedback, and readable layouts
- Built with scaling in mind: reusable patterns and consistent components
